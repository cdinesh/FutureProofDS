# FutureProofDS

Umbrella workspace for **Future Proof Data Science** projects. Each project lives in its own GitHub repository (clone them side by side or into this folder as needed).

## Projects

| Project | Repository | Description |
|---------|------------|-------------|
| **postgres-mcp-server** | [cdinesh/postgres-mcp-server](https://github.com/cdinesh/postgres-mcp-server) | PostgreSQL MCP server (`execute_sql`, `list_tables`, `get_schema`) |
| **symantic-layer** | [cdinesh/symantic-layer](https://github.com/cdinesh/symantic-layer) | Semantic layer YAML (users, sessions, subscriptions, payments) |
| **simple-data-cleaning-langgraph-workflow** | [cdinesh/simple-data-cleaning-langgraph-workflow](https://github.com/cdinesh/simple-data-cleaning-langgraph-workflow) | LangGraph workflow for simple data cleaning |

Upstream copies of some projects also exist under the [Future-Proof-DS](https://github.com/Future-Proof-DS) organization. Use those URLs if you have org write access.

## Clone all projects

```bash
mkdir -p ~/FutureProofDS && cd ~/FutureProofDS

git clone https://github.com/cdinesh/postgres-mcp-server.git
git clone https://github.com/cdinesh/symantic-layer.git
git clone https://github.com/cdinesh/simple-data-cleaning-langgraph-workflow.git
```

## This repository

`cdinesh/FutureProofDS` is a **meta repo**: shared notes (`instructions`), reference PDFs, and pointers to the project repos above. It does not vendor the project source trees.
